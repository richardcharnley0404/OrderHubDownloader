AI Quality Gate

Score every image in every job before it dispatches to a printer. Jobs with any image scoring below the threshold are held for operator review and surface as a flag on the Jobs grid. No images are altered automatically — operators approve, fix, or reject from the held-job view.

Images scoring below this number are flagged for review. Default 50. Adjust based on your lab's print quality bar. Guidance:
• Below 50 — significant quality issues likely
• 50–70 — borderline; some labs accept, some don't
• 70–85 — typical phone uploads, usually fine for print
• Above 85 — high-quality images
When ON, jobs containing any image scoring below the threshold are held back from auto-print until an operator reviews them. When OFF, jobs auto-print regardless of scores (failed images are still flagged in Job Review).

Backup & Restore

Snapshot non-sensitive OHD configuration to a network share so a failed PC can be brought back online quickly. Passwords and API keys are never written to the backup — operators re-enter those after a restore.

When enabled, OHD writes a backup at app launch (if the last successful run was more than 24 hours ago) and after the first config save of each day.
UNC paths (\\server\share\...) are most reliable. Local and mapped drives also work, but mapped drives can be unavailable when OHD launches on Windows startup before the drive is mounted.
Customer directory contains customer names and email addresses (PII). Leave checked unless your lab has a policy against storing this on the backup share.

Note: Backups never contain passwords or API keys. After a restore, re-enter your OrderHub API Key, FTP Password, S3 Secret Access Key, and Topaz API Key.
